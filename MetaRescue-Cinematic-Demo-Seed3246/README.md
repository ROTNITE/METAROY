# Демонстрационная миссия MetaEvolution Rescue — seed 3246

Два неизменяемых экземпляра **исходного генератора** (код не модифицирован):

- `basic.private.json`: мир 250×250 м, 1 дрон, 2 эвакуатора, 3 пострадавших, без событий, 240 модельных секунд;
- `fire.private.json`: **та же статическая карта** и те же три пострадавших, только вероятность пожара 100% в каждом 80-секундном окне, остальные вероятности 0%. Первое событие — пожар в 77,25 с, точка [49.302, 57.884] м. Ещё одно событие — в 163,4 с, затем распространение в 201,4 с.

Приоритетный пострадавший `person-2` расположен около [49.819, 96.737] м, приблизительно в 80 м от центра базы. Входное размещение и лента событий повторяемы. Генератору не сообщалось, какую стратегию примет контроллер.

**Подтверждено здесь:** генерация с переданными Python-исходниками, `preflight.passed == true`, 90/90 связанных дорожных узлов, корректность ленты событий, SHA-256 JSON.

**НЕ подтверждено:** обнаружение `person-2` первым, фактический выбор эвакуатора, попадание пожара на выбранную траекторию, перестроение маршрута, погрузка, доставка, FPS, корректность игрового рендера. Для этого нужен нативный запуск на Windows/Unreal и журналы.

## Как запустить, если исходный проект на компьютере содержит Unreal-карту и ассеты

1. Закройте работающий MetaRescue.exe и UnrealEditor; одновременно допускается только один Unreal.
2. Скопируйте папку `MetaRescue-Cinematic-Demo-Seed3246` целиком в **корень исходного проекта** (папка, содержащая `tools/run_mission.py`).
3. Откройте PowerShell в корне проекта.
4. Проверьте существование `Test-Path .\tools\run_mission.py` и карты `Test-Path .\unreal\MetaRescue\Content\Maps\RescueQuarter.umap`. Если `False`, используйте вместо исходников полностью распакованную штатную Windows-поставку и её документированный способ запуска, но не утверждайте, что команды ниже работают в другой структуре.
5. Запустите первый калибровочный прогон без событий:

```powershell
python -B -X utf8 tools/run_mission.py --layout .\MetaRescue-Cinematic-Demo-Seed3246\basic.private.json --name demo-basic-3246-01 --policy nsga2_nsga2 --ai-mode OFF --contest-coordination --visible --realtime
```

6. После его завершения и проверки журнала, если базовое спасение состоялось, запустите событие:

```powershell
python -B -X utf8 tools/run_mission.py --layout .\MetaRescue-Cinematic-Demo-Seed3246\fire.private.json --name demo-fire-3246-01 --policy nsga2_nsga2 --ai-mode OFF --contest-coordination --visible --realtime
```

Имена запусков должны быть уникальными; не стирать папки предыдущих запусков. Выходной путь определяется `METARESCUE_OUTPUT` (если задан) либо `D:/MetaRescue-output` в dev-сборке. Режим OFF отключает обращения к внешней LLM, но не выключает NSGA-II.

Для записи использовать OBS/захват окна. В игровом окне R — слежение за выбранным агентом, стрелки влево/вправо — переключение, цифра 7 — вид наземного робота, 1 — база, 2 — сверху; при фокусе в игровом окне. Это следует из `MRCameraPawn.cpp`, но конкретный UI может перехватывать клавиши.

**Демонстрация не является экспериментом из серии 450:** специально выбран seed и условия для съёмки. Не объединять с конкурентной серией. Если пожар не блокирует реальный маршрут, не озвучивать «объезд»: для этого требуется журнал перепланирования и подтверждённое изменение движения.
