КОНТРОЛЛЕР METAROI — ИНСТРУКЦИЯ

1. ЗАПУСК
Распакуйте архив. Откройте PowerShell в папке metaroi-controller (там лежит package.json).
Нужен Node.js 22.12+ (проверено на Node.js 24.22.1) и npm.
Выполните:
  npm install
  npm run start:controller
Оставьте терминал открытым. Остановка: Ctrl+C.
Контроллер: http://127.0.0.1:8081

2. ПРОВЕРКА В ДРУГОМ ОКНЕ POWERSHELL
  Invoke-RestMethod http://127.0.0.1:8081/v1/controller/health
Из папки распакованного архива:
  $body = Get-Content -Raw -Encoding UTF8 .\example-request.json
  $result = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8081/v1/controller/decide -ContentType 'application/json' -Body $body
  $result | ConvertTo-Json -Depth 30
Команды находятся в $result.commands, пояснение — в $result.explanation.
Это пример одного решения, а не запуск симуляции.

3. ПОДКЛЮЧЕНИЕ ЧУЖОЙ СРЕДЫ
Контроллер сам к среде не подключается. Клиент другой команды должен повторять цикл:
  а) получить наблюдение от своей среды;
  б) отправить POST /v1/controller/decide с JSON {"observation": <наблюдение>, "policy": "adaptive"};
  в) применить commands из ответа в своей среде;
  г) продвинуть модельное время и отправить новое наблюдение.
При operation="safe_stop" нужно остановить исполнение движения.
Для нового запуска используйте новый episode_id. Внутри эпизода time не должен уменьшаться.
Координаты: [x, y, z], метры, y — высота. Время — модельные секунды, энергия — от 0 до 1.
Список available_actions должен отражать реальные возможности агента.
Пример команды движения: {"agent_id":"drone-1","action":"move","parameters":{"target":[10,3,10]}}.
Реализуйте обработку всех действий, которые объявляет ваша среда, и согласуйте их семантику.
Полное описание текущего контракта: PROTOCOL.md. Пример входных данных: example-request.json.
Совместимость с произвольным API другой команды автоматически не обеспечивается: при отличиях нужен адаптер.
Обычная чужая среда передаёт базовое наблюдение без extensions.metaroi_mission.
Это расширение предназначено для большой миссии Metaroi и включает специализированный планировщик.

4. ЕСЛИ НУЖНА ПРОВЕРКА С НАШЕЙ СРЕДОЙ
В отдельном терминале из той же папки:
  npm run start:environment
Среда запустится на http://127.0.0.1:8080.
При работающих среде и контроллере в третьем терминале:
  npm run run:http
Результаты выводятся в терминал, трасса сохраняется в artifacts/big-http-run.jsonl.
Клиент run:http рассчитан на большой профиль Metaroi; для другой среды используйте её клиент или адаптер.
Для подключения чужого контроллера к нашей среде через этот клиент (при поддержке профиля):
  $env:CONTROLLER_URL = 'http://127.0.0.1:9001'
  npm run run:http
Адрес среды аналогично задаётся переменной ENVIRONMENT_URL.

5. ПОРТ И ДОСТУП
Для другого порта перед запуском:
  $env:PORT = '8082'
  npm run start:controller
По умолчанию сервис слушает только 127.0.0.1: работать с ним можно на том же компьютере.
Для локальной сети в server/service.mjs замените адрес привязки в server.listen с 127.0.0.1 на адрес сетевого интерфейса, согласуйте доступ через брандмауэр и используйте этот IP в клиенте.

6. ЧТО ВНУТРИ
server/controller.mjs — общий алгоритм контроллера.
server/public-navigation.mjs — навигация.
server/service.mjs — HTTP API.
server/large-controller.mjs и src/ — зависимости большой миссии.
server/ и scripts/ также содержат нашу среду и клиент для проверки обмена.
package.json и pnpm-lock.yaml — зависимости проекта; node_modules в архив не включён.
Исходный код скопирован без изменений. Дополнительно приложены инструкция и пример запроса.
Проверка базового алгоритма: node --test server/controller.test.mjs
