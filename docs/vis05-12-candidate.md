## 5. Обязательная нативная приёмка

Не менять acceptance на verified до нативных результатов. Нужна авторизованная UE 5.8.4 и один Unreal под project lock. В обычных GitHub Actions нет установленной UE и GPU; без авторизованного доступа к Epic container registry и достаточно диска/памяти нельзя надёжно собрать движок. Не использовать неофициальные зеркала и платные ресурсы без согласия. Portable C++ и glslang валидируют только вычислительную часть и исходные HLSL, не UE material graph и Chaos.
