# MetaEvolution Rescue на Windows

Распакуйте каталог целиком. Запустите `Start-MetaRescue.cmd` двойным щелчком или из терминала в этом каталоге. В поставке есть Win64-среда Unreal, Python, контроллер и локальная аналитика. На начальном экране загружается район 250 м редакции 2.3 с двумя катамаранами и Counterfactual Value в режиме AI OFF. В настройках можно выбрать 0–4 катамарана или загрузить предыдущую редакцию города.

Выберите «Подготовить и открыть мир». После подключения контроллера миссия ждёт запуска на паузе. Кнопки позволяют начать выполнение, поставить паузу, пройти один внешний шаг в одну модельную секунду, остановить миссию и подготовить повтор. Клавиша **2** включает верхний обзор, **1** приближает базу. Сплошные ленты показывают движение, пунктир показывает оставшийся маршрут.

Требования человека-оператора вводятся через `tools/issue_operator.py` и очередь
текущего эпизода. Порядок, форматы отмены/уточнения/подтверждения, приоритеты,
ограничения и подтверждённые границы описаны в `Operator.md` поставки
(`docs/core-operator.md` в исходниках). Доставка и исполнение видны в журнале;
сообщение «queued_locally» означает только локальную постановку.

## Повтор сценария с отказом носителя

Команда ниже использует тот же приватный пресет, что и скринкаст ознакомительного комплекта. MOCK использует локальный выбор из проверенных вариантов.

```powershell
$env:METARESCUE_OUTPUT = Join-Path (Get-Location) 'output'
.\python\python.exe -B -X utf8 tools/run_mission.py --layout presets/recovery.private.json --name packaged-recovery-01 --policy nsga2_nsga2 --controller-profile counterfactual-value --ai-mode MOCK --contest-coordination --capture-overview --capture-base-at 269
```

Для повтора выберите другое значение `--name`. Кадры и архивы появятся под `output`.

## Независимый запуск среды и контроллера

Из корня распакованного каталога в первом PowerShell запустите среду. Она откроет Core на 127.0.0.1:8130 и будет ждать reset.

```powershell
$env:METARESCUE_OUTPUT = Join-Path (Get-Location) 'output'
.\python\python.exe -B -X utf8 -m environment.main --layout presets/recovery.private.json --headless --exit-on-close
```

Во втором PowerShell выполните команду контроллера. Указанный режим не использует внешний API.

```powershell
$env:METARESCUE_OUTPUT = Join-Path (Get-Location) 'output'
$auditPath = Join-Path $env:METARESCUE_OUTPUT 'offline-usage.json'
.\python\python.exe -B -X utf8 -m controller.main --environment http://127.0.0.1:8130 --seed 2026 --health-port 8131 --policy nsga2_nsga2 --controller-profile counterfactual-value --contest-coordination --ai-mode MOCK --ai-budget $auditPath
```

Core 1.0 описан в `Core-1.0.md`. Локальный интерфейс аналитики запускается вместе с приложением. Контрольные суммы файлов поставки указаны в `SHA256.json`. В режиме LIVE укажите общий путь журнала в `METARESCUE_LIVE_BUDGET` и настройте ключ отдельно от каталога поставки.

## Сборка из исходников

`tools/package_windows.py` создаёт поставку Shipping по умолчанию. Для стендовой
сборки с инструментами Unreal Insights укажите `--configuration Development`.
Интерактивная версия Shipping и Core проверены на локальном адресе 127.0.0.1.
Обязательные файлы Scenario проверяются до cook, затем сравниваются с файлами
нативного пакета.

## Восстановление предыдущей версии

Остановите миссию в интерфейсе и закройте приложение. Распакуйте прежний
проверенный ZIP в отдельный каталог, сверив контрольные суммы поставки.
Запустите его собственным `Start-MetaRescue.cmd`. Сохранённые эпизоды каждой
сборки остаются доступны в её каталоге `output`. Для LIVE используйте тот же
общий внешний журнал бюджета.


## Лаборатория совместимости M5 (следующая сборка)

Новая схема упаковки включает `Start-M5.cmd`, `M5.md`, Python-модули
лаборатории и неизменённые независимые эталонные компоненты. Запуск из
корня распаковки:

~~~powershell
.\Start-M5.cmd
# Или с явно зарегистрированной внешней службой:
.\Start-M5.cmd --environment peer=8080
~~~

Откройте http://127.0.0.1:8766. Лаборатория работает отдельно от
приложения и аналитики; штатный запуск не поднимает Unreal, не меняет
состояние существующей миссии и не расходует LIVE-бюджет. Старт серии
требует подтверждения reset. Результаты по умолчанию сохраняются в
`output/m5-lab`. Проверка Python-части копируемой поставки в CI не
заменяет cook, проверку ZIP и испытания фактически распакованной Win64
сборки; прежняя Shipping 06 не менялась.
