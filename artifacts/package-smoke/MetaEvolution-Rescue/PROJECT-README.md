# MetaEvolution Rescue

Переносимый метасценарный контроллер спасательного роя и независимая A2X-среда.

**Текущий статус, 2026-11-09:** этап 1 принят как контракт (редакция 1.1, Core 1.0). Пользовательские v0.2/v0.3 сохранены и проверены; **текущая динамическая 2D-база — v0.3**, с открытыми замечаниями аудита. Создан отдельный C++/Unreal 5.8.4 физический стенд, выполнен 90-секундный прогон. Нормативный контроллер и подключение пяти связок к 3D ещё не реализованы; стенды не заменяют эту интеграцию.

Запуск **текущей пользовательской базы v0.3** из корня:

```powershell
python -B -X utf8 "benchmarks/metarescue-v0.3/main.py"
python -B -X utf8 -m unittest discover -s "benchmarks/metarescue-v0.3/main part/tests" -v
python -B -X utf8 unreal/launch.py --editor
```

v0.3 использует установленный Python и открывает браузер; venv создаётся только по желанию. Внешние пакеты не нужны. v0.2 сохранена в соседней папке: у неё автоматическое venv и опциональный OR-Tools, которых нет в v0.3. `benchmark/` — отдельный черновик, **не основа вместо пользовательских архивов**.

## Проверка эталонов

Из корня проекта:

    python -B -X utf8 -m unittest discover -s tests -v

Проверки используют стандартную библиотеку Python. Они проверяют авторские примеры и межобъектные инварианты, не заменяя полный валидатор схем и тесты работающего HTTP-сервера/физики.

## Нормативный этап 2

Разработчик контроллера реализует чтение Observation, select/keep, обработку результата и журнал. Разработчик среды реализует health/capabilities/reset/observation/step, три агента, сенсор, простое движение и цель. Первый обмен выполняется через HTTP; формат берётся из эталонов.

Начать можно с плоской тестовой сцены, используя трёхмерные позиции. Затем добавляются остальные обязательные сценарии, категории, связь и возмущения. ГА/GP/LLM не блокируют первый запуск.

Основные модули `environment/` и `controller/` пока являются каркасом. Приведённый выше запуск относится к самостоятельному 2D-бенчмарку, а не к нормативной интеграции.
