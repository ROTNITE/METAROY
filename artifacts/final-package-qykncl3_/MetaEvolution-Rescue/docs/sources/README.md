# Источники и полнота переноса контекста

Зафиксировано 2026-11-09. Содержимое чатов — источник истории решений, не доказательство исполнения старых обещаний. Заявления о готовности проверяются по приложенному коду и фактическим запускам.

## Сохранённые оригиналы

1. `nsga-benchmark-context-2026-11-09.txt` — **весь приложенный пользователем файл**, 538 строк, 15 581 символ после декодирования UTF-8-SIG. Сохранён без правок. Включает исходную программу бенчмарков, требования к запуску/архиву и описание v0.1.
2. `nsga-planner-thread-2026-11-09.json` — все доступные ходы ветки [«Ветка · Разработка NSGA2 планировщика спасения»](chatgpt-conversation://6af1a209-be2c-83eb-9ec0-139c4c8943f1). Получены через `read_thread`: **5 ходов, hasMore=false, nextCursor=null**. Ветка содержит v0.2, пояснение пяти связок, идеи динамики, последнее требование v0.3 и служебную точку. Более раннюю программу дополняет приложенный TXT.
3. `MetaRescue_Benchmark_v0_2.zip` — оригинальный пользовательский архив. SHA-256: `ccf4c8dd5311fe8944fcc720524cd7a74376a2ec054711ee719a23578035250e`.
4. `metarescue-v0.2-manifest.json` — SHA-256 архива/контекста и каждого из 19 импортированных файлов. Распакованная база: `benchmarks/metarescue-v0.2/`.
5. `MetaRescue_Benchmark_v0_3.zip` — последующий пользовательский релиз; SHA-256 `5b36cc61df3fda83e489fab70aa82a6d0eb695d04cc0c70a7be01c7edc2a3cdc`. Все 16 файлов полностью прочитаны и импортированы без изменения в `benchmarks/metarescue-v0.3/`; хэши в `metarescue-v0.3-manifest.json`.

Первоначально v0.3 была только требованием; после этого пользователь передал архив. Теперь сохранены обе версии и результаты их проверок. Сверка фактов нового релиза с требованиями — `docs/benchmark-v0.3-review.md`; предложенные механизмы, которых в коде нет, не считаются выполненными.
