# Evolution World — 2D MVP

**Запуск без установки библиотек** (Python 3.10+):

```bash
python main.py
```

Откроется браузер с адресом **http://127.0.0.1:8000**. Если вкладка не открылась, перейдите по адресу вручную. Ctrl+C завершает сервер.

Запуск с другими параметрами:

```bash
python main.py --width 40 --height 40 --seed 123 --port 8080
```

## Структура

```text
main.py               точка входа
Starter.py            сборщик, связывает мир и временную политику агентов
World/
    core.py           2D-мир, геном и параметры аватаров, ресурсы, действия, наблюдения, шаги
    dummy.py          динамические агенты-заглушки, выдающие команды
    server.py         HTTP API на Python stdlib
    web/
        index.html    браузерный интерфейс
        styles.css    стили
        app.js        HTML Canvas, управление и просмотр мыслей
Agent/                пустая папка для разработчика ИИ-агентов
    .gitkeep
tests/
    test_world.py     тесты игровых правил
```

## Кто за что отвечает

**Мир (`World/core.py`)** — единственный источник истины. Хранит HP, геномы, позиции, ресурсы и выполняет команды. Все агенты в начале итерации видят одинаковый снимок, но у каждого только локальная область обзора 3 клетки. Враги отображаются в наблюдении **только принадлежностью к виду и позицией**.

**Агент (`World/dummy.py`)** — временная политика. Не имеет доступа к полному миру и только возвращает команду через `decide(observation)`. Позднее заменяется на модуль из `Agent/`; он может использовать LLM, память, TALK и THINK. Сейчас `thought` — демонстрационный текст, а не вывод LLM.

**Аватар (`Avatar`)** — физический объект на карте. `Starter.py` связывает агента-решателя и аватар по `id`.

**UI** не рассчитывает игровые события, а показывает полный **наблюдательский** `snapshot()` (НЕ передавать этот снимок в LLM!).

## Контракт между разработчиками

```python
observation = world.observe(avatar)
action = agent.decide(observation)
```

Пример `Action`:

```json
{"type": "MOVE", "target": [7, 8], "thought": "Проверю соседний сектор"}
```

Допустимые `type`: `THINK`, `MOVE`, `ATTACK`, `PICKUP`, `DROP`, `BUILD`, `TALK`, `WAIT`.

- MOVE: `target: [x, y]`, не дальше `Y` шагов с учётом диагоналей и стен.
- ATTACK: `target: [x, y]`, соседняя (в т. ч. диагональная) клетка, урон `Z`. Можно атаковать союзников и блоки.
- PICKUP / DROP: `resource: "food" | "material"`, `amount: positive int`, без лимита вместимости.
- BUILD: `target: [x, y]`, соседняя клетка, стоит **5 материала**, блок HP=18.
- TALK: `recipient_id: "A-01"`, `message: "..."`; соседняя клетка, в том числе по диагонали.
- THINK: один ход без физического действия (временная заглушка имитирует текст мысли).

## Игровые правила первого этапа

- 30×30 клеток по умолчанию; граница непроходима, по диагонали двигаться разрешено.
- 3 вида по 5 агентов, отдельно в разных частях карты; разные цвета и общие стартовые зоны.
- Два ресурса — `food`, `material`. Спавн равномерный, не зависит от численности населения; ресурсы могут накапливаться на клетке.
- Каждое действие требует 1 итерацию, MOVЕ может пройти максимум `Y` клеток по доступному пути.
- Расход еды — `X` каждый ход. Если еды недостаточно, агент теряет **4 HP/ход**; при HP <= 0 умирает.
- Геном `X/Y/Z/K`, при создании проверяется `αZ + βY + δK <= γX`.
- Неограниченный инвентарь. Склад вида находится в стартовой области 3×3. На складе DROP пополняет общие запасы.
- Врагов видно по координате и виду; параметры, память, HP противника закрыты от агента.
- Одновременные атаки дают урон обеим сторонам. При конфликте движения в одну клетку побеждает минимальный ID (правило временное, детерминированное).
- Без генетического размножения: оно добавляется ПОСЛЕ подключения настоящих ИИ-агентов.
- Победа: один оставшийся вид; при 1000 ходах — число живых, затем общие ресурсы, затем суммарное HP.
- Все случайности привязаны к `seed`; `Reset` начинает с нуля с тем же seed.

## Управление в браузере

- **Запустить / Пауза**, **Шаг**, **Сброс**.
- **1×**, **5×**, **20×**, **MAX**. При MAX не нужно ждать анимацию между серверными ходами.
- Наведение на агента — краткие параметры + текст мысли.
- Клик — закрепить агента в боковом инспекторе.
- График популяций, статистика еды и материала, журнал событий.

## API

```text
GET  /api/state      текущее состояние
POST /api/step       выполнить одну итерацию
POST /api/reset      сброс, optional JSON: {"seed": 42}
```

## Дальше (не реализовано)

- В `Agent/`: LLM, собственная память, планирование, реальные сообщения/обучение.
- Эволюция, рождение, расход ресурсов на производство агента.
- Перенос отображения в 3D — ядро симулятора останется независимым от графики.

> Это MVP игровой экосистемы, не полное выполнение нормативного ТЗ хакатона.
