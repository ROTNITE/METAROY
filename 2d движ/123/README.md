# MetaRescue — Autonomous Information Gain research runner

Это исследовательское дополнение поверх Net65 + Global Dispatch + Bottleneck + Resource Predictor + Adaptive Survey. Штатный контроллер, Unreal и API не изменяются. В данной серии победитель не найден; Adaptive Survey (`range-late` в бенчмарке) сохраняется.

## Установка
Распакуйте архив отдельно. В PowerShell:

```powershell
python .\install.py "C:\path\to\MetaRescue"
cd "C:\path\to\MetaRescue"
python -m unittest tests.test_information_search tests.test_adaptive_survey -v
```

Инсталлятор проверяет SHA-256 исходных зависимостей. Если они изменены, не обходите проверку: требуется отдельное сопоставление кода. Никаких внешних пакетов дополнительно к зависимостям проекта не требуется.

## Автоматический поиск

```powershell
python -m experiments.mission_flow.auto_information --output research\information-001 --rounds 40 --patience 8 --proposals 3 --screen 24 --validate 64 --final 128 --workers 4
```

Повторите **точно ту же команду** после остановки, чтобы продолжить с сохранённой границы. Незавершённый раунд пересчитывается; завершённые серии загружаются из JSONL. Не запускайте два процесса в одной папке. Для нового бюджета/изменения кода — новый каталог и новый `--seed` (избегайте пересечения диапазонов). По умолчанию поиск останавливается после 8 раундов без подтверждённого улучшения, 40 раундов или исчерпания вариантов. Это не доказательство глобального оптимума.

Варианты: геометрическая сетка, разбиение по объявленным препятствиям, дискретное покрытие, повторная разведка по давности/полезности/ожидаемому времени эвакуации, изменение весов длительности и полезности. Генератор предлагает конфигурации в ограниченном пространстве этих гипотез, а не самостоятельно изобретает произвольные алгоритмы. Все параметры выбираются без приватного состояния среды. Геометрия рассматривается как эвристическая, не как доказательство покрытия.

Этапы: paired screening на 4 профилях, затем новый набор seed для лучшего кандидата, сравнение с текущим лидером и исходным Adaptive Survey, парный bootstrap (2000 выборок). Если появился лидер, отдельный финальный набор seed. Условия: средний M1 выше, число спасённых не меньше, суммарная энергия и время выполнения целей с отсечением не выше, нет роста аварий, нарушений резерва и отклонений пакетов; M1 каждого профиля не хуже более чем на 0,01 (можно задать `--suite-tol 0`). Для принятия требуется нижняя граница 95% bootstrap-интервала > 0. По умолчанию `--energy-tol 0`. Допустимый компромисс можно задать до начала кампании. Bootstrap для отдельных раундов не исправляет множественные проверки, поэтому финальная выборка обязательна при наличии нового лидера. Автоматического применения в production нет. Официальные M2–M7 не вычисляются. Повторные профили не заменяют нативные 3D-испытания и межкомандную приемку.

## Результаты этой работы

- 800 разработческих прогонов, 576 проверочных, 960 завершённых прогонов автоматической кампании (2336 основных строк; отдельно 96 smoke и 20 предварительных прогонов, не включённых в основной счётчик).
- 192 одинаковые проверочные карты: Adaptive Survey 1448 спасённых, M1 0.66996745, энергия 0.22495482, время целей 129.17394 с; Repeat Rescue 1458, 0.67406617, 0.22549418, 128.86604; Repeat Gain 1461, 0.67583947, 0.22658186, 129.10135. У обоих кандидатов выше энергия, у Repeat Rescue также -10 эвакуаций на стандартных картах. Стресс-профили совпали.
- 4 раунда автоматической кампании, 12 предложений, ни одного принятого. Один предварительный кандидат дошёл до проверки, но не прошёл. Воспроизведено прерывание после 3 раундов и продолжение до завершения 4-го. Состояние и сырые данные — `evidence/auto_campaign`.
- 12 целевых тестов прошли. Полная регрессия и Unreal не запускались.

Ручное воспроизведение проверочных данных:

```powershell
python -m experiments.mission_flow.benchmark_information physical 152000 48 --arms range-late info-repeat-rescue info-repeat-gain --workers 4
python -m experiments.mission_flow.benchmark_information mixed 152100 48 --arms range-late info-repeat-rescue info-repeat-gain --workers 4
python -m experiments.mission_flow.benchmark_information mixed_stress 152200 48 --arms range-late info-repeat-rescue info-repeat-gain --workers 4
python -m experiments.mission_flow.benchmark_information variable_stress 152300 48 --arms range-late info-repeat-rescue info-repeat-gain --workers 4
```
